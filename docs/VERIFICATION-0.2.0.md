# Проверка SpaceChat 0.2.0

Дата: 2026-10-23. JDK 17, Android SDK 35, Gradle 8.11.1.

## Локально

`./gradlew assembleDebug testDebugUnitTest lintDebug assembleDebugAndroidTest` — BUILD SUCCESSFUL.

- Debug APK и APK инструментальных тестов собраны.
- 22 JVM-теста, без ошибок и пропусков: 14 сетевых и 8 для Markdown / LaTeX parser.
- Lint: ошибок нет.
- Парсер проверяет четыре разделителя формул, сохранность TeX-команд, кириллицы и индексов,
  блочные формулы с пустыми строками и внутри цитат, GFM-таблицы и задачи, сочетание с Markdown,
  экранированные доллары и цены, незакрытые формулы, код без преобразования LaTeX.

## Android runtime / CI

В GitHub Actions успешно прошли 7 инструментальных сценариев на каждом из API 26 и 30: прежние проверки
Room / Keystore / навигации, Markdown и копирование кода; GFM-таблицы, задачи, ссылки,
встроенные и блочные формулы, копирование LaTeX; нативная отрисовка химических выражений,
кириллицы, процентов, дробей, индексов, матриц, интеграла и греческих символов на Canvas;
безопасный возврат к исходному тексту для некорректных и неподдерживаемых формул.
